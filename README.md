# FitPose AI 🏋️‍♂️📷

FitPose AI is a beginner-friendly fitness posture detection web project built using HTML, CSS, JavaScript, p5.js, and ml5.js (PoseNet).

The project uses your webcam to detect body keypoints in real time and provides posture feedback during exercises like squats.

---

## 🚀 Features

* Real-time webcam access
* Human pose detection using PoseNet
* Basic squat posture analysis
* Detects good squat depth
* Detects incorrect back posture
* Squat repetition counter
* Live feedback messages on screen

## 🎯 How It Works

1. Webcam captures live video.
2. PoseNet detects body keypoints such as:

* Nose
* Shoulders
* Hips
* Knees
* Ankles

3. JavaScript compares joint positions.
4. Feedback is shown:

Examples:

* Good Depth ✅
* Keep Back Straight ⚠️
* Go Lower ⬇️
* Squat Count: 5 🔥
